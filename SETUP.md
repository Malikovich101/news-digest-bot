# Настройка новостного дайджеста

Бот трижды в день собирает новые посты из публичных Telegram-каналов, удаляет
явную рекламу и повторы, а затем присылает оригинальные тексты публикаций в
личный чат.

## Что нужно добавить в GitHub Secrets

Откройте `Settings → Secrets and variables → Actions` репозитория и добавьте:

| Секрет | Где взять |
| --- | --- |
| `TG_API_ID` | [my.telegram.org](https://my.telegram.org) |
| `TG_API_HASH` | [my.telegram.org](https://my.telegram.org) |
| `TG_SESSION_STRING` | локально выполнить `get_session.py` |
| `TG_BOT_TOKEN` | @BotFather |
| `TG_CHAT_ID` | идентификатор личного чата с ботом |
| `GEMINI_API_KEY` | Google AI Studio |

`TG_SESSION_STRING` равен доступу к Telegram-аккаунту. На Windows в папке
проекта можно дважды щёлкнуть `create_session.cmd`: он запустит
`get_session.py`, запросит данные Telegram и покажет нужную строку. Не
добавляйте её в файлы проекта, переписку или переменные, доступные другим людям.

## Каналы

Укажите публичные каналы в `channels.txt`, по одному на строку, например:

```text
@durov
@example_science
```

Или отправьте своему боту одну из команд:

```text
/add @channel_name
/remove @channel_name
/list
```

Новый список применяется обычно в течение 5–10 минут. На первом запуске бот берёт
только последние 9 часов; далее он запоминает последний обработанный ID каждого
канала, поэтому не повторяет уже просмотренные сообщения.

## Расписание

Дайджест запускается ориентировочно в 08:05, 14:05 и 20:05 по Перми (UTC+5). Пять
минут сдвига нужны, чтобы не попадать в наиболее загруженную для GitHub минуту
начала часа. GitHub Actions иногда всё равно может начать задачу с небольшой задержкой.
Для проверки без ожидания откройте `Actions → News Digest → Run workflow`.

## Что делает обработка

1. Убирает пустые и слишком короткие сообщения, явную рекламу, точные копии и
   короткие репосты с той же ссылкой.
2. Передаёт Gemini только текст и идентификатор поста, чтобы найти несомненные
   смысловые дубли. Gemini не пишет, не сокращает и не перефразирует новости.
3. Присылает все оставшиеся публикации в исходной формулировке автора, по времени,
   с каналом и ссылкой на источник.
4. Если Gemini временно недоступен, всё равно доставляет посты после базовой
   фильтрации: это может дать лишний повтор, но не потерю новости.
5. Не обновляет состояние, пока сообщения не доставлены в Telegram.
