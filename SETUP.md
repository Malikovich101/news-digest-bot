# Настройка новостного дайджеста

Бот трижды в день собирает новые посты из публичных Telegram-каналов, удаляет мусор, рекламу и повторы, а затем присылает канонические оригинальные тексты публикаций в личный чат.

## Что нужно добавить в GitHub Secrets

Откройте `Settings → Secrets and variables → Actions` репозитория и добавьте:

| Секрет | Где взять |
| --- | --- |
| `TG_API_ID` | [my.telegram.org](https://my.telegram.org) |
| `TG_API_HASH` | [my.telegram.org](https://my.telegram.org) |
| `TG_SESSION_STRING` | локально выполнить `get_session.py` |
| `TG_BOT_TOKEN` | @BotFather |
| `TG_CHAT_ID` | идентификатор личного чата с ботом |
| `GEMINI_API_KEY` | Google AI Studio |

`TG_SESSION_STRING` равен доступу к Telegram-аккаунту. На Windows в папке проекта можно запустить `create_session.cmd`, который вызывает `get_session.py`. Не добавляйте эту строку в файлы проекта или переписку.

## Каналы

Укажите публичные каналы в `channels.txt`, по одному на строку, например:

```text
@durov
@example_science
```

Или отправьте своему боту одну из команд:

```text
/add @channel_name
/remove @channel_name
/list
```

Новый список применяется обычно в течение 5–10 минут. На первом запуске бот берёт публикации за последние 9 часов; далее использует per-channel watermark и durable pending queue.

## Расписание

Дайджест запускается ориентировочно в 08:05, 14:05 и 20:05 по Перми (UTC+5). Для ручной проверки откройте `Actions → News Digest → Run workflow`.

## Надёжность обработки

1. Детерминированный слой убирает пустые/короткие посты, явную рекламу, точные копии и короткие репосты с одинаковой ссылкой.
2. Gemini проверяет подозрительную рекламу и смысловые дубли. Модель не переписывает новости.
3. Новые кандидаты сохраняются в `pending_posts` до фактической доставки. Падение Gemini или Telegram не теряет собранные публикации.
4. Для Telegram сохраняются delivery receipts с явными `post_ids`. При частичном падении уже отправленные chunks не отправляются снова.
5. Длинные публикации не обрезаются: они разбиваются на Telegram chunks, поэтому исходный текст сохраняется полностью.
6. Short-term memory используется для дедупликации последних 72 часов, event memory — до 14 суток.
7. State старой версии автоматически мигрируется в актуальную структуру v6.
8. При недоступности Gemini используется безопасный fallback: deterministic candidates отправляются без AI-дедупликации, чтобы не потерять новости.
