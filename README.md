# news-digest-bot

Telegram-бот, который трижды в день собирает оригинальные новости из выбранных каналов, убирает явную рекламу, точные и смысловые дубли и отправляет готовый дайджест в личный чат.

## Расписание

Дайджест запускается в 08:05, 14:05 и 20:05 по Перми (UTC+5):

- `5 3 * * *` UTC
- `5 9 * * *` UTC
- `5 15 * * *` UTC

GitHub Actions может запустить workflow немного позже указанного времени. Watchdog подхватывает пропущенный слот после 45 минут и отменяет зависший запуск старше 15 минут.

## Как работает pipeline

1. `digest.py` получает новые сообщения из каналов через Telegram MTProto-сессию и per-channel watermark.
2. Без AI сразу отбрасываются короткие сообщения, явная реклама, точные копии и короткие репосты с одинаковыми ссылками.
3. Gemini используется только для спорной рекламы и ограниченного semantic dedup. AI-этап ограничен по количеству вызовов и времени ответа.
4. Если Gemini недоступен, новости не теряются: отправляются безопасные детерминированные кандидаты.
5. Перед отправкой кандидаты сохраняются в `pending_posts`.
6. Telegram получает сообщение целиком или несколькими частями до 3900 символов. Каждый успешно отправленный chunk фиксируется delivery receipt.
7. Watermark каналов продвигается только после успешной отправки дайджеста.
8. После успешной доставки слот помечается как завершённый. Повторный recovery того же слота пропускается.

## GitHub Secrets

Добавьте в `Settings → Secrets and variables → Actions`:

| Секрет | Где взять |
| --- | --- |
| `TG_API_ID` | my.telegram.org |
| `TG_API_HASH` | my.telegram.org |
| `TG_SESSION_STRING` | локально выполнить `get_session.py` |
| `TG_BOT_TOKEN` | @BotFather |
| `TG_CHAT_ID` | идентификатор личного чата с ботом |
| `GEMINI_API_KEY` | Google AI Studio |

`TG_SESSION_STRING` даёт доступ к Telegram-аккаунту. Не помещайте её в файлы проекта или переписку.

## Каналы

Каналы задаются в `channels.txt`, по одному на строку. Также бот поддерживает `/add`, `/remove` и `/list`.

## Локальная проверка

```text
pip install -r requirements.txt
python -m unittest discover -s tests -v
```
