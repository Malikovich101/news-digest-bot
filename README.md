# news-digest-bot

Telegram-бот, который трижды в день собирает оригинальные новости из выбранных каналов, убирает явную рекламу, точные и смысловые дубли и отправляет готовый дайджест в личный чат.

## Как это работает (супер-версия = оба ИИ)

1. `digest_pipeline.py` забирает новые посты из `channels.txt` по per-channel `last_message_id` + по времени (первый запуск — 9 часов назад).
2. Детерминированный фильтр без AI отбрасывает короткие, явную рекламу (`#реклама`, `erid`) и точные копии.
3. Gemini проверяет только спорное: подозрительную рекламу и смысловые дубли. **Каждый этап изолирован** — падение проверки рекламы не роняет дедуп.
4. Сбор по каналам идёт с паузой 0.5с и обработкой `FloodWait` — Telegram не завалит весь запуск.
5. Результат бьётся на части по 3900 символов и отправляется в твой чат, исходный текст не режется.
6. Состояние (`state.json`) сразу коммитится в репозиторий — переживает перезапуски и не зависит от кеша Actions. При падении придёт уведомление в Telegram.

## Быстрый старт

1. Добавьте в `Settings → Secrets and variables → Actions`: `TG_API_ID`, `TG_API_HASH`, `TG_SESSION_STRING`, `TG_BOT_TOKEN`, `TG_CHAT_ID`, `GEMINI_API_KEY`.
2. Укажите каналы в `channels.txt` или командой боту `/add @channel`.
3. Запустите `Actions → News Digest → Run workflow` для проверки.

## Расписание

08:05, 14:05 и 20:05 по Перми (UTC+5) — это `5 3 * * *`, `5 9 * * *`, `5 15 * * *` UTC в `.github/workflows/digest.yml`.

## Надёжность

- `pending_posts` + `delivery_receipts` — не теряет посты при падении Gemini/Telegram и не шлёт дубли.
- `recent_news` 72ч / `event_memory` 14 дней — ловит повторы даже на следующий день.
- Watchdog предупредит, если предыдущий запуск пропал >8ч.
- При недоступности Gemini — безопасный fallback без AI, чтобы не потерять новости.
